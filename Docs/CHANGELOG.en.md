## [1.0.0] - 2026-02-10

### Added
- **Initial Release**: First release of the BotanyPots Trees datapack.
- **Vanilla Tree Recipes (8)**: Added growing recipes in BotanyPots for all vanilla Minecraft tree types (Oak, Birch, Spruce, Acacia, Dark Oak, Jungle, Cherry, Mangrove).
- **Documentation**: Added README in English and Italian, MIT License, and `.gitignore`.

## Development Roadmap

### Phase 2 - Expansion 📋
