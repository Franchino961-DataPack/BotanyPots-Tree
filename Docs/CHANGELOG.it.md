## [1.0.0] - 2026-02-10

### Aggiunto
- **Prima Release**: Prima versione del datapack BotanyPots Trees.
- **Ricette Alberi Vanilla (8)**: Aggiunte ricette di crescita in BotanyPots per tutti i tipi di alberi vanilla di Minecraft (Quercia, Betulla, Abete, Acacia, Quercia Scura, Giungla, Ciliegio, Mangrovia).
- **Documentazione**: Aggiunti README in inglese e italiano, Licenza MIT e `.gitignore`.
